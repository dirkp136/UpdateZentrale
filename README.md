# Update-Zentrale

Android-App für mein Galaxy: zeigt an einer Stelle, wo Updates anstehen, und springt direkt dorthin.

- App-Updates aus Google Play und Galaxy Store
- Google Play-Systemupdate (Mainline) und Google-Systemkomponenten
- Galaxy Wearable für Ring und Watch
- Android-Version, One UI, Sicherheitspatch mit Alterswarnung

Keine Berechtigungen, kein Netzzugriff. Ab Android 10.

## Bauen

Android Studio öffnen oder `./gradlew assembleRelease`. Die fertige APK liegt unter `app/build/outputs/apk/release/`.
